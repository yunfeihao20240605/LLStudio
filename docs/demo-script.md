# LLStudio 演示视频脚本

## 基本信息

| 项目 | 说明 |
|------|------|
| **作品名称** | LLStudio——基于AI的外语听说智能训练软件 |
| **视频格式** | MP4 |
| **建议时长** | 8-10 分钟 |
| **录制方式** | 屏幕录制 + 麦克风同步讲解 |
| **分辨率** | 1920×1080 或更高 |
| **帧率** | 30fps |

---

## 录制前准备清单

- [ ] 应用编译正常，能流畅运行
- [ ] 准备好演示视频素材（3-5 分钟英语教学视频，带清晰人声）
- [ ] AI 服务已配置 API Key，能正常回复
- [ ] 腾讯云语音识别已配置密钥，能正常识别
- [ ] 麦克风工作正常，音质清晰
- [ ] 录屏软件设置正确（分辨率、帧率、音频源）
- [ ] 关闭无关应用通知，避免录制中弹窗

---

## 视频脚本

### 第1段：开场介绍（约 1 分钟）

**画面**：启动 LLStudio 应用，展示主界面

**讲解词**：

> 大家好，今天为大家演示的作品是"LLStudio——基于AI的外语听说智能训练软件"。这是一款专为外语听说训练设计的桌面应用，集成了视频播放、波形分析、字幕管理、片段循环训练、跟读录音、语音识别、AI辅导等功能，帮助学习者高效提升外语听说能力。

**操作**：

- 启动 LLStudio 应用
- 展示主界面三栏布局：
  - 左侧：资源库侧边栏
  - 中间：视频播放区 + 波形显示区
  - 右侧：字幕/笔记/AI 三标签面板
- 简要鼠标悬停各区域，让评委看清整体布局

---

### 第2段：视频加载与波形生成（约 1 分钟）

**画面**：通过"文件 > 打开视频"加载一段英语教学视频

**讲解词**：

> 首先加载一段外语教学视频。软件会自动生成音频波形，先快速生成预览波形。波形支持最高 2000 倍缩放，随着倍数提高，会自动加载更高精度的细节波形，让学习者可以精细放大观察语音的细微变化，便于定位关键片段。

**操作**：

- 点击菜单"文件 > 打开视频"
- 选择视频文件，等待加载
- 展示波形自动生成过程（预览波形先出现，细节逐步加载）
- 指出波形上方的播放进度指示线
- 简要播放几秒，展示波形与播放同步
- 演示调整波形缩放倍数，展示倍数提高时自动加载高精度细节波形
- 指出倍速最高支持 2000 倍，可精细放大观察语音细节

---

### 第3段：片段循环训练 + 手动添加字幕（约 2.5 分钟）

**画面**：选择一段难点片段，启动循环训练，反复听后手动写字幕

**讲解词**：

> 听力训练的核心工作流是——先选区循环聆听，再尝试写出听到的内容。在波形上拖选一段难以听懂的区间，设置重复次数和循环间隔，点击开始训练。软件会在 A-B 区间反复播放，学习者专注聆听。训练过程中可以随时调整播放速度和音量，比如放慢语速仔细听辨，或调大音量听清细节。听懂后，在右侧字幕面板中手动输入听到的文字，完成字幕创建。字幕会自动关联到该时间区间，播放时自动高亮。

**操作**：

1. **选区**
   - 在波形上拖选一段区间（约 5-10 秒）
   - 展示选区高亮和 A/B 时间标记

2. **设置训练参数**
   - 在左侧侧边栏设置重复次数（如 3 次）
   - 设置循环间隔（如 2 秒）

3. **启动循环训练**
   - 点击"开始训练"按钮（或按空格键）
   - 展示循环播放过程
   - 指出训练进度显示（已完成循环数 / 总循环数）
   - 演示调整播放速度（如降至 0.75 倍速），展示放慢后更易听辨
   - 演示调整音量，展示音量增大后听清细节

4. **手动添加字幕**
   - 训练结束后，切换到字幕标签
   - 在字幕编辑框中手动输入听到的英语文字
   - 点击"添加字幕"按钮
   - 展示字幕创建成功，字幕列表中出现新条目

5. **验证字幕跟随**
   - 播放视频，展示当前播放到该区间时字幕自动高亮
   - 视频画面中也同步显示字幕叠加

---

### 第4段：语音识别辅助（约 1.5 分钟）

**画面**：再选一段更难的片段，循环后仍然听不出，使用语音识别

**讲解词**：

> 当遇到语速快或发音模糊的片段，反复循环后仍然听不出来时，可以借助语音识别功能。点击语音识别按钮，软件会调用腾讯云语音识别服务，自动识别选区内的语音内容，并将识别结果填充到字幕编辑框中。学习者可以在识别结果基础上修改纠正，既节省时间又保留了学习过程。

**操作**：

1. **选择更难的片段**
   - 在波形上拖选另一段区间（语速较快或发音模糊的部分）
   - 启动循环训练，反复听 2-3 遍

2. **展示"听不出"的情况**
   - 暂停播放，稍作停顿，表现难以听清

3. **使用语音识别**
   - 点击语音识别按钮
   - 等待识别完成（展示识别中的状态指示）

4. **查看识别结果**
   - 识别结果自动填入字幕编辑框
   - 在识别结果上做少量修正（如修正个别单词）

5. **保存字幕**
   - 点击"添加字幕"按钮
   - 展示字幕创建成功

---

### 第5段：跟读录音与对比（约 2 分钟）

**画面**：录制用户的跟读，播放对比

**讲解词**：

> 听力训练不仅需要听，还需要说。软件支持跟读录音功能——在波形区点击录音按钮，跟随原音录制自己的发音。录制完成后，波形区会同时显示原音和录音波形，方便对比。还可以切换到录音训练模式，循环播放自己的录音进行模仿练习。软件还提供录音降噪功能，支持轻度、标准、强力三档降噪。

**操作**：

1. **开始录音**
   - 在波形区点击录音按钮
   - 跟随原音录制一段跟读
   - 点击停止录音

2. **双波形对比**
   - 展示原音波形和录音波形上下对照
   - 指出录音与原音的对齐关系

3. **录音训练模式**
   - 切换到录音训练模式
   - 设置循环次数
   - 展示循环播放自己的录音

4. **录音降噪（可选快速演示）**
   - 点击菜单"麦克风 > 录音降噪 > 标准"
   - 展示降噪处理完成提示

---

### 第6段：AI 辅导（约 1.5 分钟）

**画面**：切换到 AI 面板，针对当前字幕内容提问

**讲解词**：

> 软件内置 AI 辅导功能。当播放到某句字幕时，AI 会自动获取当前字幕的上下文。AI 面板内置了三个快捷提示按钮——"这句话怎么发音"、"请分析连读和弱读"、"重音应该放在哪里"，学习者一键即可发送常见问题。AI 会结合当前字幕内容给出针对性解答，帮助学习者理解语音现象，提升听辨能力。AI 服务支持多种模型配置，可适配不同的外语。

**操作**：

1. **切换到 AI 面板**
   - 点击右侧"AI"标签

2. **播放视频到某句字幕**
   - 播放视频，让某句字幕成为当前活跃字幕
   - 指出 AI 面板已自动获取当前字幕上下文

3. **点击快捷提示——这句话怎么发音**
   - 点击"这句话怎么发音"提示按钮
   - 展示 AI 回答，讲解整句的发音要点

4. **点击快捷提示——请分析连读和弱读**
   - 点击"请分析连读和弱读"提示按钮
   - 展示 AI 回答，指出连读和弱读位置及发音方式

5. **点击快捷提示——重音应该放在哪里**
   - 点击"重音应该放在哪里"提示按钮
   - 展示 AI 回答，标注句子中的重音位置

---

### 第7段：笔记与学习管理（约 1 分钟）

**画面**：在某个时间点创建笔记，展示资源库和已完成视频列表

**讲解词**：

> 学习过程中可以随时记录笔记，笔记关联到视频的具体时间点，点击即可跳转回放。保存的学习片段可以设置标记，比如按场景划分为"对话"、"独白"、"新闻"等类别，然后选择相同标记的片段连续播放，进行分类集中训练。左侧资源库会记录所有学习过的视频，自动保存播放进度，方便下次继续学习。已经学完的视频可以移到"已完成"列表中，便于追踪学习进度。

**操作**：

1. **创建笔记**
   - 切换到"笔记"标签
   - 在某个时间点创建一条笔记
   - 输入笔记内容（如"这里需要注意连读现象"）

2. **笔记跳转**
   - 点击已有笔记的时间链接
   - 展示视频自动跳转到对应时间点

3. **展示资源库与片段标记**
   - 指向左侧资源库侧边栏
   - 展示视频列表、播放进度记忆
   - 展示片段列表中已保存的学习片段
   - 为片段设置标记（如"对话"、"独白"等场景分类）
   - 选择相同标记的多个片段，展示连续播放功能

4. **展示已完成视频列表**
   - 将一个已学完的视频移到"已完成"列表
   - 展示已完成列表中的视频

## 录制建议

| 项目 | 建议 |
|------|------|
| **录屏工具** | macOS 用 QuickTime Player（文件 > 新建屏幕录制）；Windows 用 OBS Studio |

| **语音识别** | 提前在设置中配置好腾讯云语音识别密钥 |
| **操作节奏** | 每个功能演示后稍作停顿，让评委看清效果 |
| **画面质量** | 分辨率 1920×1080 以上，帧率 30fps |
| **讲解风格** | 自然流畅，避免照念稿件，适当口语化 |

## 演示逻辑链

整个视频呈现的学习闭环：

```
听（循环训练）
  → 写（手动添加字幕）
    → 听不出时借助AI（语音识别辅助）
      → 说（跟读录音对比）
        → 问（AI 辅导讲解）
          → 记（笔记记录）
```

先学后辅，循序渐进，体现"以学习者为中心"的教学理念。
