# LLStudio 申报材料

## 作品名称

LLStudio——基于AI的外语听说智能训练软件

## 教学实施情况及教学效果

本软件于2026年8月开发完成，计划于2026-2027学年第一学期在外语听力教学中投入试用。整个项目的教学理念为：先学后辅，循序渐进，体现"以学习者为中心"。软件基于建构主义学习理论，采用"听—写—说—析"四阶训练法，将传统被动听力训练转变为主动探究式学习。

软件已在开发阶段进行了内部测试，验证了核心功能的可用性和稳定性。在测试中，通过片段循环训练、波形可视化、AI语音分析等功能，能够有效帮助学习者识别连读、弱读、重音等语音现象。预计正式投入教学后，可显著提升学生的听力理解能力和语音感知能力。

## 教学成果

本软件为自主研发的教学工具，已具备完整的功能体系，包括视频播放、波形分析、字幕管理、片段循环训练、跟读录音、语音识别、AI辅导等模块。软件采用 Rust + QML 技术架构，支持 macOS、Windows、Linux 三平台，具备跨平台部署能力。

后续计划在试用学期末进行教学效果评估，收集学生反馈，持续迭代优化。

## 推广情况

软件已完成开发，计划按以下路径推广：

1. **第一阶段**（2026-2027第一学期）：在外语学院听力课程中试用，收集师生反馈；
2. **第二阶段**（2026-2027第二学期）：根据试用反馈优化后，推广至全校外语课程；
3. **第三阶段**：整理使用案例，通过教研活动向兄弟院校分享推广。
