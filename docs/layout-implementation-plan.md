# LLStudio 响应式布局实现方案

## 1. 目标

在不破坏现有视频播放、波形、字幕、笔记、AI、录音和训练功能的前提下，增加可由用户手动选择的布局方式，改善 `1024×768` 等小屏幕下的使用体验。

核心原则：只调整 QML 布局层，不修改 Rust 业务逻辑、媒体处理逻辑和现有 Bridge 接口。

## 2. 保持当前默认布局

首次启动和未保存布局设置时，继续使用当前布局：

```text
左侧：学习库与学习控制
中间：视频
中间下方：波形
右侧：字幕、笔记、AI、学习片段列表
```

这样可以保证 macOS、Linux 以及大屏 Windows 用户的现有界面和操作习惯不变。

不修改以下功能：

- 视频播放和定位；
- FFmpeg、mpv 调用；
- 波形生成、缩放和精确定位；
- A/B 选区及拖动逻辑；
- 字幕、笔记和 AI 功能；
- 录音、录音对比和训练流程；
- Rust 与 QML Bridge 接口。

## 3. 左侧面板整体折叠

当前左侧的 `LibrarySidebar` 作为一个整体进行折叠。

折叠后：

- 不销毁 `LibrarySidebar`；
- 不清除学习库、训练状态或当前选区；
- 面板宽度收缩到窄条或隐藏区域；
- 保留一个始终可用的展开按钮；
- 展开后恢复用户上次使用的宽度。

这样可以避免折叠后重新加载数据，也不会中断正在进行的训练。

## 4. 右侧面板整体折叠

当前右侧的 `learningDetailsPanel` 作为一个整体进行折叠，其中包含：

- 字幕；
- 笔记；
- AI；
- 学习片段列表。

折叠后：

- 保留内部组件和页面状态；
- 不销毁字幕、笔记或 AI 页面；
- 保留一个始终可用的展开按钮；
- 展开后恢复用户上次使用的宽度。

## 5. 波形位置手动选择

增加波形位置选择：

```text
波形位置：视频下方 / 视频右侧
```

### 5.1 视频下方模式

保持当前布局：

```text
视频
波形
```

适合大屏幕和已有用户习惯。

### 5.2 视频右侧模式

将中间播放区域改为：

```text
视频 | 波形
```

波形可以使用接近完整的窗口高度，从而改善：

- 波形显示高度；
- A/B 竖向定位线高度；
- 播放指针显示；
- 小屏幕下的精确拖动操作。

## 6. 菜单调整与用户手动控制

### 6.1 移除编辑菜单

现有“编辑”菜单不再保留。在增加布局菜单时，一并移除“编辑”菜单及其菜单入口，避免顶部菜单功能重复或占用空间。

如果“编辑”菜单中存在仍然需要保留的功能，应在实现前逐项确认去向；布局相关操作统一放入新的“布局”菜单，不继续挂在“编辑”菜单下。

### 6.2 布局手动控制

建议在主工具栏增加布局控制按钮：

```text
显示/隐藏学习库
显示/隐藏详情面板
波形：下方 / 右侧
```

用户可以自由组合：

- 左侧面板展开或折叠；
- 右侧面板展开或折叠；
- 波形位于视频下方或右侧。

也可以将上述操作集中放入新的“布局”菜单，例如：

```text
布局
├─ 显示/隐藏学习库与学习控制
├─ 显示/隐藏字幕、笔记、AI 与学习片段
└─ 波形位置：视频下方 / 视频右侧
```

布局不自动切换、不弹出空间不足提示，也不强制改变用户选择。用户根据实际视觉效果自行调整。

## 7. 布局设置保存

将以下布局状态保存到本地：

```text
leftPanelExpanded
rightPanelExpanded
waveformPlacement
```

默认值保持当前行为：

```text
左侧展开
右侧展开
波形位于视频下方
```

设置保存应复用现有本地设置机制，不修改学习数据表和数据库结构。

## 8. 小屏幕使用方式

在 `1024×768` 屏幕下，推荐用户手动选择：

```text
左侧折叠
右侧折叠
波形位于视频右侧
```

这样可以将更多空间留给视频和波形。

如果用户选择展开所有面板，程序仍然尊重用户选择，不自动调整布局。用户可以通过折叠按钮和分隔条自行调整。

Windows 显示缩放可能使 Qt 的逻辑尺寸进一步变小，因此布局实现需要避免依赖过大的固定最小尺寸，同时保留必要的控件可用空间。

## 9. 实现顺序

1. 在 `Main.qml` 中增加三个布局状态：左侧面板状态、右侧面板状态和波形位置状态。
2. 为左侧 `LibrarySidebar` 增加整体折叠和展开能力。
3. 为右侧 `learningDetailsPanel` 增加整体折叠和展开能力。
4. 移除现有“编辑”菜单及其入口。
5. 增加新的“布局”菜单，并确保折叠后仍然可以重新展开面板。
6. 让中间 `playbackWorkspace` 支持垂直和水平两种布局方向。
7. 保存和恢复用户布局设置。
8. 检查全屏视频模式，确保全屏时不受布局状态影响。
9. 完成跨平台构建和功能验证。

## 10. 功能验证

需要验证以下场景：

- 默认布局与当前版本一致；
- 左侧面板折叠和展开；
- 右侧面板折叠和展开；
- 波形上下布局与左右布局切换；
- 视频播放、暂停、拖动和定位；
- A/B 标记显示、拖动和选区同步；
- 波形缩放、自动跟随和精确定位；
- 字幕选区、笔记和 AI 上下文同步；
- 录音、录音对比和训练流程；
- 全屏视频模式；
- Windows `1024×768` 及高 DPI 缩放；
- macOS 和 Linux 现有默认布局及功能。

## 11. 兼容性原则

本方案只改变界面容器的尺寸、排列方向和显示状态，不改变媒体处理、数据存储和训练逻辑。

大屏幕下继续使用当前布局，小屏幕下由用户手动折叠面板和调整波形位置。因此可以在改善 Windows 小屏幕体验的同时，最大限度保持 macOS、Linux 以及现有正常功能不变。
